# SASS Guia de Instalación

## Prerequisitos
Antes de comenzar, asegúrese de tener instalado lo siguiente:
- [Node.js](https://nodejs.org/) (que incluye npm)

## Instalación

### Usando npm
1. Abre tu terminal.
2. Ejecute el siguiente comando para instalar SASS globalmente:
    ```sh
    npm install -g sass
    ```

## Verificando Instalación
Para verificar que SASS se ha instalado correctamente, ejecute:
```sh
sass --version
```
Debería ver el número de versión de SASS instalado.

## Uso
Para compilar un archivo SASS a CSS, utilice el siguiente comando:
```sh
sass --watch ./scss/style.scss ./css/style.css
```
